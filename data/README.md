# Data

`healthcare-dataset-stroke-data.csv` contains 5,110 rows and 12 fields from the [Stroke Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset) published by Kaggle user `fedesoriano`.

The application excludes records with unknown smoking status or missing values, leaving 3,426 complete educational records for modeling. The source page identifies a confidential upstream source, restricts use to education, requests author credit, and lists the files as copyrighted by their original authors. The file is retained in this private repository for course-project reproducibility only.
