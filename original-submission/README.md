# Original course submission

These R Markdown and R files are preserved from the HGEN 612 final-project
folder without code edits. They show the original student workflow,
experiments, and dashboard iterations.

The polished, reproducible version is in the repository root. The original
files reference course-folder assets such as `healthcare.csv` and image files,
so they are retained for provenance rather than guaranteed one-click
execution.

Credential files, recovery codes, local histories, and unrelated binary
artifacts were intentionally excluded.
